    📝 주문 상세 수정

    ☁️ Firebase 클라우드 연결 설정

    Firebase를 연결하면 모든 PC에서 실시간 동기화됩니다.
    아래 설정값은 Firebase Console에서 복사해서 붙여넣으세요.

    📋 설정 방법 (5분 소요)
    1. console.firebase.google.com 접속 → 구글 로그인
    2. 프로젝트 추가 → 프로젝트명 입력 (예: dental-clinic) → 만들기
    3. 왼쪽 메뉴 빌드 → Firestore Database → 데이터베이스 만들기 → 테스트 모드 선택
    4. 왼쪽 상단 ⚙️ → 프로젝트 설정 → 하단 "내 앱" → </> 웹 클릭 → 앱 등록
    5. 표시된 firebaseConfig 값을 아래에 입력
    ⚠️ 설정값은 이 기기 브라우저에 저장됩니다. 다른 PC에서도 동일한 값을 입력하세요.
